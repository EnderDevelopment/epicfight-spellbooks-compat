# EpicFightSpellbooksCompat

EpicFightSpellbooksCompat is a Minecraft Forge mod designed to prevent crashes when Epic Fight and Iron's Spells 'n Spellbooks are installed together. It ensures compatibility between these mods by redirecting the rendering of GeckoLib animatable entities to GeckoLib, thus avoiding conflicts with Epic Fight's renderer.

## Install

1. Download the latest release of EpicFightSpellbooksCompat from the [GitHub releases page](https://github.com/EnderDevelopment/EpicFightSpellbooksCompat/releases).
2. Place the downloaded `.jar` file into the `mods` folder of your Minecraft instance.

## Use

1. Launch Minecraft with the Forge profile.
2. Ensure both Epic Fight and Iron's Spells 'n Spellbooks are installed and enabled.
3. Start a new world or load an existing one. The mod will automatically handle the rendering of GeckoLib animatable entities, preventing crashes.
